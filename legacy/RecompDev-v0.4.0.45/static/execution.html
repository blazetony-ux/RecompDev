RECOMPDEV / NATIVE EXECUTION / v0.4.0.14

Native Execution

Generate, compile and run source-attested Z80 C++. On missing ROM code (including fixed vectors and isolated instructions), recover with Ghidra, rebuild and retry. Track hotspots, sampled CPU registers and the first video/sound port activity within a bounded step and time budget.

EXPERIMENTAL
Not an emulator and not yet a playable or parity-verified conversion. This pilot attempts bounded bank recovery, then stops on missing code or unsupported semantics. The preliminary video/PSG compatibility layer does not establish frame or sound accuracy. A compiled instruction is not evidence of full behavioural parity.

Architecture capabilities

Shared interfaces and honest stage-by-stage blockers; native x86-64 compilation is currently integrated only for the Z80/Master System pilot.

Execution provenance

Native project files and diagnostics are created under evidence/native-pilot-v0420/jobs/ on your own computer, including the generation report, compiler log, runtime log, SHA-verified complete event chunks and optional background-only PPM preview.

The output CMake project contains generated bank-qualified Z80 C++, a partial Master System hardware bus, and a bounded execution harness. The executable reads your original ROM locally for data and hardware state. No ROM file is embedded in the downloadable RecompDev release.
