## What is delivered

A native `rd_artifact_store` shared-library ABI v1 with CPU/console-neutral binary `put`/`get` APIs, content-SHA object deduplication, immutable producer+target+ABI descriptors, per-ROM immutable portable capsule manifests, hash rechecking on every lookup, safe bounded relative paths and fail-closed corruption handling. This store does not encode SMS banks or Z80 instructions; such semantics remain provider-owned. The C++ controller uses the same generic implementation for source-attested native recovery adapter inputs.

On a fresh `run --rom`, the controller first searches its independent user-scoped artifact store. If no capsule exists, the existing v24 registry searches legacy evidence; eligible complete sessions are migrated once and used from the portable materialisation. Automatic retention publishes compatible future sessions. A capsule includes verified Ghidra IR, Rizin hypothesis artifacts, reconciled hypotheses, source/bank verified observations and generated C++ sources when present; legacy absolute stop paths are normalised to verified relative paths. Existing provider re-attestation remains mandatory. `cache --rom` exposes a `PORTABLE_CAPSULE_FOUND_REATTEST_ON_USE` status on a portable match. Users can relocate the entire store via `RECOMPDEV_ARTIFACT_ROOT`.

## Validation and explicit limitations

New CTests: `v04925_universal_artifact_store`, `v04925_artifact_store_plugin_abi`, `v04925_portable_provider_replay`. The latter intentionally removes its original synthetic recovery session, relocates the store, and executes the maintained Ghidra-analysis and bank-overlay import checks using only the retained capsule. Other existing Windows tests must remain green. Original 642 historical baseline files are untouched.

**BLOCKED:** This is **not** a compiled native game DLL/executable cache and does not provide hot-loading or exact-state gameplay continuation; the native project may still recompile. It is not a working Mega Drive/PS1 recompiler. Portable stored *bytes* do not imply reusable machine code across host architectures or compiler ABIs. The embedded machine-readable orchestration document is a source-checked compatibility input within the capsule, not a reference to an old evidence folder. Ghidra/Rizin tool identity and provider versions can invalidate reuse and trigger new analysis. Passing neutral 960-frame Bank Panic native execution does not prove gameplay parity, and runtime qualification remains FALSE. **Windows owner full 81-test suite and real-ROM portable migration/independent replay are still pending.**

## Source-only release safeguards

The v24 Git main commit is the mandatory source baseline. The permanent Git-managed release installer verifies package and old/new per-file SHA-256, staged source, preserved history and native CTests before a source-only promotion. No active runtime binary swap, no original ROM edits, no baseline tampering, no GitHub publication without explicit owner permission. The release ZIP is a source delta, not a standalone full Windows binary distribution.
