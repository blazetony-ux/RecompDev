The compiled controller stores users' jobs **outside Git** with the original ROM hash, uniquely named immutable sessions, provenance, target frame budget, attempt progress and an `events.jsonl` stream. `--logging info` defaults to concise output; `debug`, `warning` and `error` select console severity threshold while all emitted controller records remain on disk. Errors or unknown/missing external tool authorization and ROM changes block progress. Native controller schedules the next bounded provider execution automatically after a source-attested `MAX_RECOVERY_ROUNDS_REACHED` result. A history import is reverified by the v0.4.9.14 provider and native translator, **not** a saved process/binary replay. Max 16 sessions, 8 rounds per provider batch, bounded output and two consecutive no-improvement sessions terminate automatically.
