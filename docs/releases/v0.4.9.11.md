## Implemented, demonstrable source

- Compiled `RecompDev.exe --stage native-orchestrate` is an actual controller route, not a manual multi-command recipe. It calls the source-only `analysis_integration` migration adapter, which invokes owner-approved local Ghidra `analyzeHeadless` (for native P-code function export) and Rizin `aflj` (for corroborating function boundaries) using the preserved, tested analysis algorithms; it never executes the historical recovery runner or original production native runtime.
- Analyzer inputs, external executable roots, source SHA-256, instruction byte hashes, immutable evidence directory and round limits are checked. The original Z80/Ghidra source exporter is used for a full initial `0xC000` mapping and historically recovered `bank-functions.json` may be reused through explicit `--history-root` with native source/target identity gates. Rizin initial-mapping entrypoints are new source-verified discovery hints, **not** trusted native code or bank proofs. When an approved Ghidra backend is available and native execution stops at untranslated code, the controller also reconstructs the **observed** 48 KiB mapper view and re-runs the original Ghidra export script with the actual stopped PC as a seed. It retains only the source-byte-attested function instructions in the observed 16 KiB slot as a bank-context overlay; the compiled translation DLL independently checks this overlay against the original ROM. A mismatched mapper, RAM-mapped slot or unmatched stop instruction fails closed.
- The compiled native translation tool and native CPU/machine plugin compile generated source. The controller then runs the resulting native application in bounded headless mode; only actual untranslated-code results produce labelled `recompdev.native.app.stop.v1` evidence containing observed PC/SP/physical ROM offset and mapper. Those are reauthenticated by native discovery before subsequent translation. Repeated gaps, lack of new verified instruction coverage, tool errors, timeouts and max-rounds failures stop explicitly.
