# RecompDev v0.4.9.29 — Operational source and runtime staging lifecycle (SOURCE-ONLY PROMOTION)

**Status: owner-authorised for SOURCE-ONLY Git main/tag promotion, based on promoted `workspace/v0.4.9.28` commit `724d190eeb0928ebab4e242e9aba4d2cef016505`.** `-Mode Validate` and, subject to the canonical installer repeating all gates, `-Mode Install` are permitted. No new runtime is active or authorised for activation. The [authoritative roadmap](../project/ROADMAP.md) and [v29 prebuild](../project/PREBUILD-v0.4.9.29-OPERATIONAL-LIFECYCLE.md) define this scope.

## Implemented functional changes

- Hardware-neutral Git publisher validates queue entries, automatically retries outstanding generated-source commits with bounded backoff during gameplay, retries at next launch even without a new module, and exposes a dedicated `retry-pending` subcommand and pending ROM count through `status`. Local checked-in generated C++ remains authoritative during network failures.
- Installer stages and verifies a SHA-256-locked native runtime candidate from its own Windows build inventory under the external validation transaction, with **no production activation**. A new runtime stage utility refuses tampering/overwrites and makes the not-yet-qualified state explicit.
- Post-install Git source publication now checks the final pending queue and declines to report `VERIFIED` when work remains pending. Installer still preserves real user-generated source, original per-game Git ancestry, active binary lockfiles and previous immutable Git tags.
- Tests cover genuine Git offline/online retry, idle live-session retry, malformed pending file protection, verified restore, immutable runtime stage and active-runtime non-interference. CPU, machine and translator ABIs remain unchanged.

Independent retry lifecycle rerun passed **5/5**; production idle retry reported 0 pending; all five staged native binaries matched recorded SHA-256 hashes; active runtime lockfile remained unchanged (SHA-256 `1469FD22B3064648C1008079AAE2CD830F91B59BAC91BC29CE2353C46EEFE5E2`). The replacement package is regenerated with updated documentation and manifest hashes, requires normal SHA-pinned installer checks, and does not bypass the installer. **Unverified/deferred:** live unattended real-GitHub outage/restart retry, fresh-home Fantasy Zone/Shinobi restore, real-game 2,400-frame and input regressions, active runtime cutover/rollback, standalone EXE export, independent video/audio/hardware parity.
