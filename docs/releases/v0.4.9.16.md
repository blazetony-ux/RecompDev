### One-package release bootstrap

The current root permanent installer is still an older version because `main` remains v0.4.9.9. For v0.4.9.16 the owner can verify one ZIP against the independently provided expected SHA-256, expand that same ZIP into a new temporary extraction folder, and invoke the *package-pinned* `files/Install-RecompDev-Release.ps1` to run `-Mode Validate`. The package supplies all source changes and its manifest declares the verified dev parent. On a successful Windows test run the updated script writes `dev/v0.4.9.16`, printing its actual Git SHA, and leaves `main` and the active runtime unchanged. There is no second downloaded Git bundle. If the pinned dev parent is absent/mismatched, it fails closed instead of rewriting history. A source-only portable Git-index regression does not substitute for Windows PowerShell acceptance.
