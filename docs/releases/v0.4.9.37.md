# v0.4.9.37 — universal memory effects, source-attested native handoff and origin safeguards

**Release track:** `infrastructure-source`, `git-main-only-no-runtime`, source-promotion candidate. **Baseline:** owner-installed `workspace/v0.4.9.36`, commit `01ec528fb7bb2bf92fbaa43a53834d7fa0ad0ab1` after 104/104 Windows CTests, preservation of 642 original files, and verified generated-game-source publication. The active production runtime is not modified by this candidate. Owner Windows acceptance requires 108 CTests, documentation/Python governance, historical preservation and hash-pinned Git rollback before `main` promotion.

## Delivered

1. **Interchangeable precise memory effects:** the CPU decoders describe register-indexed writes, stack-pointer movement, counted block-copy destinations and their effects; only machine providers decide whether a write aliases mapper registers. Known safe SP, IX/IY, DE/BC and address ranges preserve known bank state; unknown or mapper-overlapping writes remain fail-closed. Special cases handle 16-bit wraparound. This is hardware-neutral orchestration, not a Shinobi-specific patch. Full Z80 decoding/flags are still unsupported.
2. **Safer cross-ISA facts:** abstract-state intersections conservatively merge *speculative* caller continuations within the same machine mapping and return context; M68000 initial SP and call/RTS changes are tracked, exception returns are left unresolved; MIPS branch-link effects are not incorrectly applied to untaken conditional branches. Independent providers own all ISA details.
3. **Offline provenance comparison:** `analyze --compare-to OLD_DIR` (repeatable up to eight times) compares byte-hash/PC/physical-offset identities to source-matched old evidence. The versioned `regression-comparison[s].json` explains retained, missing, new, and reclassified candidates. It explicitly rejects mismatched source files and tampered old inventories. Counts are not coverage qualification.
4. **Experimental native handoff:** `RecompDev.exe analyze-native --rom FILE --analysis DIR --out NEW_DIR --rights-confirmed` reads the source SHA, format/CPU/machine provider hashes, instruction hashes and candidate confidence classes. With a tiny supported CPU-provider `lift_probe`, it emits independently buildable C++ **control-flow probes**. Z80 supports NOP, JP absolute, JR and HALT; M68000 supports NOP, BRA and STOP. No general CPU flags, data memory, machine hardware, audio, video, input, interrupts or portable-game exporter is implemented by this probe. PS-X EXE/MIPS and all unsupported instructions return explicit unsupported status. The existing standalone native-game exporter remains separate and unchanged. This is a tested bridge toward its real native-source integration, not completion of that integration.
5. **Opt-in origin verification:** preserve `-PublishOrigin` and its existing atomic non-forced source branch+tag push, adding an independent remote-main ancestor preflight and post-push hash verification with evidence under the release transaction. On divergence, fail safely with the already installed local commit/backup retained. The helper never pushes itself and the game-derived source Git repo remains separate. The permanent installer used to *install* v37 is the previously installed v36 script; this new preflight applies when the promoted v37 installer script is used in subsequent transactions.

## Owner interface

```powershell
& $exe analyze --rom 'C:\Roms\example.sms' --out 'C:\Projects\RecompDev-Evidence\offline-v37-example' --budget 40000 --compare-to 'C:\Projects\RecompDev-Evidence\offline-v36-example'
& $exe analyze-native --rom 'C:\Roms\example.sms' --analysis 'C:\Projects\RecompDev-Evidence\offline-v37-example' --out 'C:\Projects\RecompDev-Evidence\offline-native-probe' --rights-confirmed
```

The second command is an **experimental and deliberately limited translation witness**; it may reject real games when the reset instruction or needed control transfers are not liftable by the installed CPU plugin. To compile its generated proof source, use `cmake -S OUTPUT_DIR -B BUILD_DIR` then `cmake --build BUILD_DIR --config Release`. Only rights-cleared source may be used for exports. This is not the production game-native P-code pipeline or game compatibility verification.

## Acceptance and BLOCKED gates

**Locally implemented tests:** 13 new precise-memory/recomparison checks, 5 native-handoff tests (including real standalone GCC/MSVC C++ compilation on supported test platforms), 4 Git-origin tests using an actual disposable bare repo, and one compiled-controller handoff test. Existing offline ABI v2, standalone exporter and native runtime regressions remain mandatory. The four new named CTests bring the Windows total to **108**. Linux excludes two historical-archive prerequisites absent in the non-owner source checkout; owner Windows must run all tests.

**Still blocked:** complete statically proven code inventory, new real-ROM recovered blocks, whole-ISA semantic correctness, jump-table resolution, decompression/overlays, generated native game-module consumption by the v34 standalone exporter, hardware/video/audio/input parity, simultaneous Mega Drive CPU scheduling, PS1 disc/BIOS support and arbitrary-ROM compatibility. No game window is launched by offline analysis. Native probe execution cannot be represented as real-game playability.
