# RecompDev v0.4.9.28 — Automatic generated-source Git lifecycle (owner-accepted source-only release)

**Status (2026-11-09): OWNER-ACCEPTED FOR GIT SOURCE-ONLY PROMOTION.** Based on GitHub-published `workspace/v0.4.9.27` commit `3db4190043136514fe8f68be0f35aa383951778f`. The permanent Windows installer must re-run complete SHA-verified native and historical tests during `-Mode Install`, then create the new commit, annotated `workspace/v0.4.9.28` tag and verified rollback bundle. Optional `-PublishOrigin` atomically pushes RecompDev main and the new tag. This approval does not qualify or activate runtime binaries; audio and independent hardware parity remain unverified.

## Implemented source changes

1. **Immediate checkpoints:** A receipt from the still-running native guest confirms module activation before the controller checkpoints its verified generated source. Checkpointing is now per activated region rather than every four; no guest-code speculation or direct game patching is added.
2. **Automated shared-main publication:** A background queue, independent of game input/frame delivery, publishes verified per-ROM source Git commits using Git subtree to the configured private `RecompDev-plugins/main`. Existing ROM directories are refreshed in place; new ROMs receive new folders rather than branches. The SHA-256-keyed provenance record includes the exact original per-game Git commit and tree for future restoration. No ROM bytes, DLL binaries or original console files enter Git.
3. **Offline durability:** Network failure, unclean shared worktree or remote conflicts report pending and preserve original local source commits. No `--force`, ref deletion, destructive reset, automatic conflict override or gameplay failure. A successful source checkpoint is independent of remote availability.
4. **Automatic install-time recovery:** After verified local release commit, tag and external backup, the installer discovers or configures the existing clean sibling shared checkout, fetches `origin/main` and restores **original per-game Git histories** to `RECOMPDEV_HOME/gs/<ROM-SHA>` without overwriting dirty or diverged local repositories. It can run on a fresh installation provided a configured shared checkout and Git access are available. A remote outage is reported as pending, never concealed as success.
5. **Release publication:** An explicit `-PublishOrigin` option atomically publishes the main RecompDev controller branch and *new* annotated tag only after all local release gates. Local release rollback does not attempt to undo remote operations. The main RecompDev repository never receives game-derived source.

This is a universal source/artifact governance component; its identity is SHA-256, Git commit/tree and toolchain fingerprint. It has no machine or ISA-specific imports. RecompDev's original standalone ROM-free executable goal remains a future milestone, not implemented here. The existing `.dll` and cache layers stay outside Git and are reused or rebuilt according to their strict compatibility fingerprints.
