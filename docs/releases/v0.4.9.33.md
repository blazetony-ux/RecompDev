## Actual defect and implementation

Shinobi shared generated source had an append-only consolidated native library under `generated/roms/<ROM SHA256>` while provenance pointed at an older original game commit. The mismatch prevented `restore-all`. The synchroniser now safely reconstructs a source-history commit with the exact current subtree via `git subtree split`, requires the previous original commit to be its ancestor, connects that commit to shared main using a non-destructive `ours` merge (preserving content and unsquashed original lineage), and only then updates the provenance source commit/tree together. The repair runs in the existing cross-process Git lock during restore. Shared commits are never reset or rebased. The game repository fast-forwards only if its local history is compatible; divergent local commits are preserved with a diagnostic.
