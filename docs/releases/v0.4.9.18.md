# RecompDev v0.4.9.18 — evidence routing and source-attested analysis reuse

**Date:** 2026-11-07. **Release track:** `infrastructure-source` / `git-main-only-no-runtime`. **Baseline:** Published and owner-verified `workspace/v0.4.9.17`, Git main `ab8745242c81e5e6cbb5754bac0d3710f289e4bc`. **Approval:** [PREBUILD-v0.4.9.18](../project/PREBUILD-v0.4.9.18.md) and [DEVELOPMENT-CONTRACT](../project/DEVELOPMENT-CONTRACT.md); original binding [PREBUILD-v0.4.9.7.md](../project/PREBUILD-v0.4.9.7.md) remains applicable.

## Delivered in the candidate

- `RecompDev.exe configure --evidence-root DIR`: new job sessions under `DIR/v0.4.9.18/jobs`, diagnostics under `DIR/v0.4.9.18/diagnostics`. The owner's previous `--workspace` setting `C:\Projects\RecompDev-Evidence\v0.4.9.17` automatically resolves to its parent evidence root. AppData only retains config and last-job reference; legacy AppData and older version-scoped jobs remain discoverable. Diagnostic export always writes into **current** version regardless of original job root.
- `workspace.diagnostics_export` adds `coverage-diff.json` with per-cycle address-only physical/PC/length differences, classified observed mapper/PC/physical execution stops, and analysis reuse status. Translation manifests are read and SHA-256 matched to the ROM identity but never packaged raw; no game ROM, C++/DLL binaries or secret/absolute paths are included.
- `analysis_integration.analysis_reuse` checks source identity, authorised Ghidra/Rizin executable hashes and paths, maintained provider/Java script hashes, prior output-file hashes, Ghidra instruction bytes and deterministic reconciliation before copying unchanged analysis into the new session. Cache misses rerun external tools; artifact tampering aborts instead of laundering evidence. Historical `--resume-from` imports still validate mapper/ROM/Ghidra overlays. The newest authenticated stop and overlay are ordered first in translation inputs; this is **not** a novel ISA algorithm.
- Release validation can create `dev/v0.4.9.18` from exact `main` v17 Git parent, avoiding manual bundle transfers. `Install` may promote source only after the full Windows acceptance suite, with active runtime unchanged and local Git rollback bundle.
