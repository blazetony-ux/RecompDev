## Windows validation bootstrap correction (2026-11-06)

The initial permanent-installer candidate rejected `CHANGELOG.md` because its filename filter treated all `.md` files as Mega Drive ROMs. The corrected candidate allows Markdown source, verifies it as UTF-8 text without NUL bytes, and still rejects protected historical paths and binary ROM extensions. Release-manifest hashes and independent ZIP SHA-256 were regenerated. **This is a candidate-only installer correction, not proof of Windows validation or promotion.**

### Validation bootstrap correction 2 (2026-11-06)

The permanent installer stages tracked source with `git archive`. An immutable
legacy evidence file (`legacy/RecompDev-v0.4.0.45/evidence/baselines/sms-seven-v0436.json`)
is intentionally Git-ignored but is still one of the 642 files required by
`migration/source-integrity-manifest.json`. Git staging therefore omitted it.
The installer now restores missing or byte-mismatched manifest-declared frozen files from
the unchanged live checkout into the isolated staging directory after checking
exact byte counts and SHA-256 values. This also handles Git-archive line-ending
normalisation. The complete historical verification
remains mandatory; no frozen source files are rewritten or bypassed.
No runtime, CPU plugin, or native translation feature changed in this fix.
