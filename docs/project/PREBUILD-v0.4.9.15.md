- All CPU/format/machine/runtime/video/audio/translator plugin source and C ABIs unchanged; no platform/game-specific offsets or ROM-title checks.

## B. Configuration / usability contract

`RecompDev.exe configure --ghidra ABSOLUTE_PATH --rizin ABSOLUTE_PATH [--allow-tool-root DIR...]` records explicit executable authorization. `RecompDev.exe run --rom ROM [--logging LEVEL] [--target-frames N] [--max-cycles N] [--rounds-per-cycle N]` automatically resolves active source root, DLL folder, previous state and an external job/evidence home; `RecompDev.exe resume [--job ID] [--logging LEVEL]`, `status`, `inspect` report individual durable attempts. `RECOMPDEV_HOME` supplies isolated per-user state location; default is OS user data, **never** source or frozen trees. Missing configured tools, unsupported platform/CPU, stale ROM, malformed job state, evidence mismatch and repeated non-progress must fail closed. Controller API does not hardcode SMS/Z80; the existing analyzer may explicitly refuse unsupported plugin capabilities.
