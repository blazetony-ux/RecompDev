# v0.4.9.22 prebuild — native monitor responsiveness and ROM-agnostic watch filters

**Architecture binding:** Generic C++ controller plus interchangeable CPU, hardware, video, analysis, translator, runtime, monitor and format providers; no Shinobi, SMS or Z80 rules in controller or viewer. Read [DEVELOPMENT-CONTRACT.md](DEVELOPMENT-CONTRACT.md), original owner-approved [PREBUILD-v0.4.9.7.md](PREBUILD-v0.4.9.7.md), and [HANDOVER.md](HANDOVER.md).

**Owner baseline:** v0.4.9.21 source promoted to `main` `87a9ed588e9e155e6a1c7d2fa3132072f60a4603` after Windows 72/72 CTests and 642/642 preserved historical files. Real Shinobi preview reached 1,800 host output frames and the native Win32 monitor correctly subscribed, but its trace field was apparently unresponsive until execution stopped. This is a failed live UI acceptance despite passing automated tests. Independent reference gameplay parity and non-neutral input remain BLOCKED.

**v0.4.9.22 implementation:** Move Winsock reading off UI and bound per-subscriber/display queues; update Win32 on 100-ms timer, append only new trace rows, maintain 2,000-entry history and non-interference with guest execution. Add searching and filtering by CPU-logical PC, physical offset, opcode class and event type, matches-only, next/previous, and follow-latest. Forward repeatable `--monitor-pc`/`--monitor-pc-range` parameters through compiled controller into private event producer so requested addresses are not silently skipped by `--monitor-every`. Show transport/UI dropped display counts. No debugger breakpoints/step support and no claims of exhaustive trace beyond configured native-event cap.

**Other ROMs:** New `tools/Run-RecompDev-ROM-Smoke.ps1` runs bounded independent jobs for all non-Shinobi `.sms` ROMs in a supplied directory, no imported Shinobi history and no plugin mutation. It writes per-ROM SHA/job/status/frame/diagnostic summaries in a versioned evidence folder. A failure on any other ROM is useful evidence; do not overgeneralize Shinobi findings.

**Acceptance criteria:** Linux CMake build, 74 or more CTests including high-volume native monitor stress, source-bound real preview smoke, exact watch-override tests, 47+ Python workflow tests, documentation governance, source ZIP manifest and SHA, owner Windows full acceptance/GUI responsiveness/live filter test. **BLOCKED:** independent reference emulator/interactive input/video/audio/state parity, second-ROM validated execution, source-neutral native analysis provider ABI, full legacy migration and 68000/MIPS compiled translation. Protected 642 legacy/baseline files and original jobs remain untouched. Release is `infrastructure-source` only (`git-main-only-no-runtime`).
